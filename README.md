# Aegis

Анонимный мессенджер с упором на безопасность. **Статус: этап планирования (Фаза 0), кода пока нет.**

- Регистрация по **нику и паролю**: без номера телефона и почты
- Сквозное шифрование, данные хранятся только на устройстве
- Быстрый вход по **PIN**, после переустановки по нику и паролю
- **Федерация:** любой поднимает свой сервер прямо из клиента
- Список серверов с подписанными галочками ✓ (официальные и проверенные)
- Пользователей нельзя найти поиском, контакты добавляются по приглашению
- Сообщения, звонки и видеозвонки в фоне
- Плагины и моды

> Мы не заявляем «самый защищённый в мире». Это нужно заслужить открытым кодом, независимым аудитом и временем.
