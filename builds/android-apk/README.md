# Android APK — Установка и настройка стартовых серверов

## Готовые файлы в этой папке
1. **`aegis-messenger-release.apk`** — основной подписанный релизный APK для установки на телефон Android (Android 9.0+ / API 28+).
2. **`aegis-messenger-debug.apk`** — тестовая сборка APK.
3. **`rebuild-apk.ps1`** — скрипт для локальной пересборки APK из исходников `apps/aegis-android`.

## Как работают стартовые серверы (Тор НЕ обязателен!)
- При первом запуске приложение **сразу подключается напрямую по статическому IP** к стартовому серверу `185.220.101.42:8443` (`Official ✓✓`, Цюрих).
- **Никакой Tor / Orbot / VPN устанавливать не нужно** — любой человек скачивает APK, создаёт ник и пароль и сразу общается.
- Если вы подняли свой сервер со статическим IP (из папки `builds/server/`), откройте вкладку **«🌐 Серверы (Static IP)»**, введите свой `IP:8443` и нажмите **«⚡ Подключить по статическому IP в 1 клик»**.
