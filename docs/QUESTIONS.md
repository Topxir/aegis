# Вопросы владельцу

Статусы: ❓ открыт · ✅ отвечен

| # | Вопрос | Статус | Ответ |
|---|---|---|---|
| Q-1 | Платформы старта: Android + десктоп, затем iOS? | ✅ | Да: старт Android + Desktop, позже iOS (см. D-0005). |
| Q-2 | Recovery и стандарты пароля? | ✅ | Строгий стандарт пароля (мин. длина, >= 3 заглавных, строчные, цифры, спецсимволы, проверка энтропии и защита от брутфорса через Argon2id + OPAQUE + PoW). 24 слова не обязательны (опционально). При проблемах — анонимные тикеты в поддержку (через приложение и будущий сайт поддержки). |
| Q-3 | Модель сети: аккаунты на сервере или односторонние очереди? | ✅ | Гибрид максимальной анонимности: OPAQUE-аккаунт (по `KDF(ник, соль)`) для входа/синхронизации + односторонние анонимные очереди (SMP-style) для переписки + Sealed Sender + Anti-DDoS (PoW, rate-limit, blind tokens) + IP/VPN/Tor щит-индикатор и локальный DLP-сканер (Leak Guard) против случайной отправки карт/CVV/почт/телефонов без ложных срабатываний. |
| Q-4 | Группы и файлы в MVP или позже (Фаза 6)? | ✅ | 1:1 сообщения и базовая безопасность в Фазах 1–3, группы (MLS) и тяжёлые файлы — в Фазе 6. |
| Q-5 | Лицензия AGPL-3.0 подходит? | ✅ | Да, AGPL-3.0 принята (см. D-0003). |
| Q-6 | Кто подписывает каталог серверов и сертификаты поддержки (один ключ или порог 2-из-3)? | ✅ | На старте 1 ключ фонда, но формат каталога и код (`aegis-directory`) изначально поддерживают пороговую схему M-of-N (Ed25519). |
| Q-7 | Нужна история после переустановки (зашифрованный бэкап) или «чистый лист»? | ✅ | По умолчанию локальное хранение + опциональный зашифрованный облачный/файловый бэкап (ключ из пароля через Argon2id). Также: генератор анонимных ников, мультиаккаунт до 3 профилей на устройстве бесплатно, свыше 3 — разблокировка через анонимный донат-токен (Privacy Pass / blind signature). |
| Q-8 | Бюджет на внешний аудит в Фазе 8? | ❓ | Определится ближе к Фазе 8 (до этого — внутренний аудит, фаззинг, открытая спецификация). |
| Q-9 | Языки интерфейса на старте: RU + EN? | ✅ | Да, RU + EN со старта (см. D-0012). |
