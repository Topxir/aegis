# Отчёт T-0011 — Фаза 8: Стартовые анонимные серверы со статическим IP (без обязательного Tor), сборка APK/Desktop/Server в папку `builds/` и релиз на GitHub
Дата: 2026-10-22  Агент/сессия: opencode / Фаза 8 (Финализация, Параллельный Red-Team Аудит, Билды и GitHub Release)

## Что сделано
- **Стартовые анонимные серверы со статическим IP без обязательного Tor (`D-0019`):**
  - В `aegis-directory` (`BuiltInDirectory`) добавлено поле `static_ipv4: Option<[u8; 4]>`, метод `direct_static_ip_entries()` и 3 встроенных стартовых статических IP-узла, не требующих Tor (`185.220.101.42:8443 ✓✓` Zurich, `91.108.56.110:8443 ✓✓` Frankfurt, `193.163.125.18:8443 ✓` Iceland) + 4-й опциональный `.onion` узел.
  - В `aegis-transport` добавлены `ProxyConfig::direct_starter` и `format_static_ipv4_endpoint` (`kill_switch_enabled: false` для прямого стартового профиля, чтобы обычные пользователи без Tor/VPN подключались сразу «из коробки»).
  - В `aegis-launcher` добавлен генератор однокомандного развёртывания сервера на любом VPS со статическим IP (`generate_static_ip_vps_script`) и `AEGIS_BIND_HOST: "0.0.0.0"`.
  - В `aegis-serverd` реализована поддержка `--bind=0.0.0.0` / `--bind <ip>` и переменных окружения `AEGIS_BIND_HOST` / `AEGIS_BIND_PORT`.
  - В `aegis-ui-desktop` и `apps/aegis-android` по умолчанию выбран прямой стартовый сервер со статическим IP (`185.220.101.42:8443 ✓✓`) без обязательного Tor, добавлено переключение между стартовыми серверами в 1 клик и поле подключения к любому собственному статическому IP (`IP:порт`).
- **Параллельный Red-Team аудит Фазы 8 (`B-0056`..`B-0067`):**
  - Найдены, задокументированы в `docs/BUGS.md`, исправлены и покрыты регрессионными тестами 12 новых проблем безопасности и корректности (`B-0056`..`B-0067`), включая синхронизацию направления цепочек в `RatchetSession::dh_ratchet_step`, `impl Drop for AccountVault`, битовую маску уникальности слов в `RecoveryPhrase`, очистку строк в `EncryptedVaultDb::crypto_wipe`, фильтрацию утечки `raddr`/`rport` в `filter_ice_candidate`, защиту от обхода `verify_app_pin("")` после паник-сброса и устранение `SecurityException` Android 14 `foregroundServiceType`.
- **Сборка релизных артефактов в отдельную папку `builds/` (`D-0020`):**
  - `builds/android-apk/` — подписанный релизный APK `aegis-messenger-release.apk`, отладочный `aegis-messenger-debug.apk`, скрипт `rebuild-apk.ps1` и документация.
  - `builds/desktop/` — `aegis-desktop.exe`, `run-desktop-gui.bat`, `run-self-test.bat`.
  - `builds/server/` — `aegis-serverd.exe`, `run-static-ip-server.bat`, `deploy-static-ip-vps.sh`, `docker-compose.yml`, `cloud-init.yaml`, `starter-servers.json`.
  - `builds/SHA256SUMS.txt` и `.github/workflows/release-apk.yml` для автосборки на GitHub Actions.
