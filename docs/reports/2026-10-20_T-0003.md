- Настроен `deny.toml` (`cargo-deny`): запрет уязвимых, неподдерживаемых и `yanked`-зависимостей, wildcard-версий, неизвестных реестров и git-источников; белый список лицензий (`AGPL-3.0-or-later`, `MIT`, `Apache-2.0`, `BSD-2/3-Clause`, `ISC`, `MPL-2.0`, `Unicode-3.0`, `Zlib`, `CC0-1.0`).
- Создан `.github/workflows/ci.yml`: автоматический запуск сканера секретов, `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace --all-targets`, `cargo-deny` и `cargo-audit` на каждый `push` и `pull_request`.
- Создан `.github/PULL_REQUEST_TEMPLATE.md` по чек-листу `AGENTS.md §6` (Definition of Done).
- Добавлены скрипты pre-commit/CI сканирования секретов и токенов: `scripts/check-secrets.sh` и `scripts/check-secrets.ps1`.
- Создан корневой `Cargo.toml` и 11 крейтов ядра строго по карте модулей (`AGENTS.md §3`, `§4`) с жёсткими линтерами (`unsafe_code = "forbid"`, `unwrap_used = "deny"`, `expect_used = "deny"`, `panic = "deny"`):
  - `crates/aegis-crypto` (`ZeroizingBuffer` с редактированием `Debug` и занулением памяти через `black_box` + `compiler_fence`, `constant_time_eq`, `PowChallenge`, `PowVerifier`)
  - `crates/aegis-identity` (валидатор строгой политики паролей `validate_password` с проверкой >= 12 символов и **>= 3 заглавных букв** по D-0006, генератор анонимных ников `generate_nickname`, менеджер мультиаккаунта `AccountSlotManager` на 3 бесплатных слота + `SupporterPass` по D-0010, автомат блокировки PIN `PinGuard` с поддержкой `DuressTriggered`)
  - `crates/aegis-storage` (`SCHEMA_VERSION = 1`, `EncryptedStoreHeader`, `crypto_wipe`)
  - `crates/aegis-protocol` (`PROTOCOL_VERSION = 1`, паддинг пакетов в фиксированные корзины `256 / 1024 / 4096 / 16384` байт, локальный DLP-сканер `LeakGuard` с проверкой карт по **алгоритму Луна (Luhn)** + BIN + контексту `CVV/MM/YY`, e-mail, телефонов и собственного логина без ложных срабатываний по D-0009, `SupportTicket`)
  - `crates/aegis-transport` (`NetworkRouteStatus`, `evaluate_network_shield` с детекцией обрыва VPN/туннеля и Kill Switch по D-0008)
  - `crates/aegis-calls` (`CallConfig` с принудительным `relay_only: true` и `require_e2ee_media: true` по умолчанию)
  - `crates/aegis-server` (`compute_pow_difficulty`, `QueueQuota`, `DEFAULT_QUEUE_TTL_SECS`)
  - `crates/aegis-directory` (`ServerBadge`, пороговая проверка подписей `M-of-N` `ThresholdPolicy` и списков отзыва `verify_threshold_attestations` по D-0011)
  - `crates/aegis-launcher` (`LaunchTarget`, `build_launch_plan` с предупреждением для Android-режима)
  - `crates/aegis-plugins` (`PluginManifest`, `validate_manifest` с полным запретом доступа к ключам)
  - `crates/aegis-ffi` (единая граница FFI для UI, `Locale::Ru` / `Locale::En`, `core_version_info`)
