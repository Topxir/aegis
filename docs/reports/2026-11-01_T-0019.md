# Отчёт T-0019 — Owner-контроль, локальные пуши и глубокая кастомизация
Дата: 2026-11-01  Агент/сессия: DeepSeek V4.1 Flash Free

## Что сделано
- Убраны общие каналы/группы из дефолтного каталога и списка чатов. Остался единственный `📢 Канал Owner` (`channel://owner`), плюс люди `@owner` (Shadow, алиасы `ceo`, `erd`) и `@topxir`.
- Owner-привилегии:
  - Desktop: аккаунт `@owner` + локальный ключ устройства `~/.aegis-owner.key` (создан из реквизитов туннеля `485cca70-…`).
  - Android: аккаунт `@owner` (ключ устройства остаётся на ПК).
  - Только Owner может писать в `channel://owner`, создавать каналы и добавлять несколько `@юзов`.
- Пуш-уведомления (без FCM/GMS):
  - Desktop: `Notification` Web API + всплывающий тост в WebView, поля `push_enabled` / `sound_enabled` / `push_title` / `push_text` в `/api/poll`.
  - Android: `AegisNotifications` + `NotificationCompat`, foreground-service polling каждые 20 с, разрешение `POST_NOTIFICATIONS`, подавление дублей при открытом приложении.
- Кастомизация в профиле (Desktop и Android): 6 цветовых тем, 4 фона чата, 3 стиля пузырей, 3 размера текста, статус-эмодзи, био, переключатели пушей/звука/анимаций/автообновлений.
- Сервер: `FederationServerState` сохраняет очереди, auth-хэши и каталог в `~/.aegis-server-state.tsv`; старые `aegis_news` / `aegis_lobby` отфильтровываются при загрузке.
- Ники отображаются без `@username`; `@юз` виден только в карточке профиля.

## Что не сделано / отложено (и почему)
- Android не проверяет файл ключа ПК; Owner-права на телефоне определяются аккаунтом `@owner` (см. `D-0029`).
- Полноценный background push при убитом процессе ОС не гарантируется без FCM/UnifiedPush; текущий foreground-service polling — компромисс без Google-зависимостей.
