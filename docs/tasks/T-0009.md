# T-0009 — Групповые чаты MLS, файловые вложения, бэкапы и 24 слова восстановления
Модуль(и): `aegis-protocol`, `aegis-storage`, `aegis-identity` · Фаза: 6 · Приоритет: высокий · Тип: feature

## Цель
Реализовать групповые чаты с эпохами и ротацией ключей (`GroupChatSession`), зашифрованные вложения с индивидуальными ключами, экспорт/импорт зашифрованных бэкапов и опциональную фразу восстановления из 24 слов.

## Критерии приёмки
- [x] `GroupChatSession` принудительно меняет эпоху и ключ группы при добавлении/удалении участника
- [x] Зашифрованный экспорт/импорт локальной БД (`export_encrypted_backup` / `import_encrypted_backup`)
- [x] Детерминированная генерация и проверка контрольной суммы фразы из 24 слов (`RecoveryPhrase`)
