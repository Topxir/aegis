# T-0005 — Сервер MVP, протокол 1:1, инвайты и очистка метаданных
Модуль(и): `aegis-protocol`, `aegis-transport`, `aegis-server` · Фаза: 2 · Приоритет: критический · Тип: feature

## Цель
Реализовать одноразовые ссылки-приглашения / QR (`ContactInvite`), 60-значный Safety Number, автоматическую очистку EXIF/GPS метаданных из JPEG/PNG (`strip_media_metadata`), `ViewOncePayload` и богатые типы сообщений (`MessageContent`).

- [x] Самоуничтожающиеся контейнеры `ViewOncePayload` (`open_view_once_payload`) и таймеры `MessageExpirationPolicy`
