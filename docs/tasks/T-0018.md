# T-0018 — Нативный десктопный клиент Windows (`tao`/`wry` WebView2), чистый мессенджер-интерфейс Desktop и Android, комплексный аудит ядра/сервера/UI и сборка релизных артефактов

Модуль(и): `aegis-crypto`, `aegis-identity`, `aegis-storage`, `aegis-protocol`, `aegis-transport`, `aegis-server`, `aegis-directory`, `aegis-plugins`, `aegis-ffi`, `aegis-ui-desktop`, `apps/aegis-android`, `builds/` · Фаза: 13 (Native Desktop & Clean Messenger UI Hardening) · Приоритет: критический · Тип: security | feature | bugfix

## Цель
1. Сделать из десктопного клиента `aegis-desktop.exe` настоящее нативное Windows-приложение в собственном окне (`tao 0.37.2` + `wry 0.57.1` WebView2) с автоматическим fallback на системный браузер при отсутствии WebView2.
2. Полностью переработать интерфейс Desktop (`crates/aegis-ui-desktop/src/lib.rs`) и Android (`AegisComposeApp.kt`) в чистый, аккуратный и интуитивно понятный мессенджер (боковая колонка чатов, пузыри переписки, компактная строка ввода, инфо-панель и нижняя навигация), сохранив все защитные механизмы (`LeakGuard`, проверка смены ключа, `Safety Number`, PIN-блокировка чата, `Kill Switch`, маскировка под калькулятор, `Duress PIN` и `Panic Wipe`).
3. Провести перекрёстный аудит всех крейтов ядра, сервера и UI без выдуманных багов, устранив все подтверждённые уязвимости.
4. Удалить старые сборки, пересобрать актуальные релизные артефакты (`aegis-desktop.exe` + `WebView2Loader.dll`, `aegis-serverd.exe`, `aegis-messenger-release.apk`) и обновить `builds/SHA256SUMS.txt`.

## Критерии приёмки
- [x] `aegis-desktop.exe` запускается на Windows в собственном нативном окне WebView2 (`1180×780`), запрещает переходы вне `http://127.0.0.1:<port>`, новые окна (`NewWindowResponse::Deny`), разрешения (`PermissionResponse::Deny`) и DevTools (`with_devtools(false)`).
- [x] Локальный HTTP-сервер `aegis-ui-desktop` поддерживает `POST /action` с `Content-Type: application/x-www-form-urlencoded` (чтение до `Content-Length` с лимитом 64 КБ) и не передаёт пароль входа в URL.
- [x] Все существующие команды `/action?cmd=...` и тесты `aegis-ui-desktop` (15/15) проходят без регрессий; экраны `CalculatorDisguise` и `PanicWiped` полностью изолированы и не содержат данных чатов/профилей.
- [x] Android Compose UI (`AegisComposeApp.kt`) переведён на чистый мессенджер-интерфейс (онбординг, список серверов, чаты, пузыри сообщений, профиль, диалоги Safety Number / приглашений / нового чата / подтверждения стирания) и собирается через `gradlew assembleRelease` без предупреждений.
- [x] Все 102 теста Rust workspace и `cargo clippy --workspace --all-targets -- -D warnings` проходят с нулём ошибок и предупреждений.
- [x] Старые сборки удалены; свежие артефакты и `builds/SHA256SUMS.txt` сформированы.

## Вне рамок (чего НЕ делать)
- Не ослаблять криптографические проверки, `LeakGuard`, `Kill Switch` или `FLAG_SECURE` ради визуального эффекта.
- Не добавлять внешние аналитические SDK или сетевые шрифты/скрипты.

## Риски / модель угроз (кратко)
- Навигация WebView на внешний URL или открытие всплывающего окна могли бы привести к утечке локального порта или фишингу: купировано белым списком `uri == allowed_root || uri.starts_with(&allowed_path)` и `NewWindowResponse::Deny`.
- Передача пароля в `GET`-запросе оставляет его в истории навигации формы: купировано переводом формы входа на `POST` (`application/x-www-form-urlencoded`).
- Утечка метаданных заблокированного чата в списке чатов или поиск по закрытому чату: купировано скрытием превью и пропуском сообщений при `isLocked == true`.
