# T-0006 — Защищённый UI-фасад, маскировка приложения и анти-скриншот политика
Модуль(и): `aegis-identity`, `aegis-ffi` · Фаза: 3 · Приоритет: высокий · Тип: feature

## Цель
Обеспечить безопасный мост для Android/Desktop UI: онбординг (генератор ников, строгая оценка пароля, PIN + Duress PIN), маскировку под калькулятор/заметки и мгновенную паник-кнопку.

## Контекст
- `docs/PLAN.md` §8.1, §9, §11, §14
- `docs/DECISIONS.md` D-0013, D-0014, D-0018

## Критерии приёмки
- [x] Проверка секретного выражения калькулятора (`check_calculator_unlock`) за константное время
- [x] Паник-кнопка (`trigger_panic_button`) мгновенно затирает ключевую обёртку `PinGuard`
- [x] Поддержка индивидуальной блокировки чатов (`ChatPinLock`)
