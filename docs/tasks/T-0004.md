# T-0004 — Ядро Фазы 1: Криптопримитивы, OPAQUE-идентичность и зашифрованное хранилище
Модуль(и): `aegis-crypto`, `aegis-identity`, `aegis-storage` · Фаза: 1 · Приоритет: критический · Тип: feature

## Цель
Реализовать эталонные криптографические примитивы (SHA-256, HMAC-SHA256, HKDF-SHA256, ChaCha20-Poly1305 AEAD по RFC 8439, гибридный PQXDH-комбинатор, Double Ratchet и PoW-решатель), OPAQUE-регистрацию/вход (`AccountVault`), паник-кнопку, режим маскировки под калькулятор, индивидуальный PIN на чат и локальную зашифрованную БД `EncryptedVaultDb`.

## Критерии приёмки
- [x] SHA-256, HMAC-SHA256, HKDF-SHA256 и RFC 8439 ChaCha20-Poly1305 проходят официальные тестовые векторы NIST/RFC
- [x] Гибридный `combine_pqxdh_secrets` и `RatchetSession` защищают от повторов и обрабатывают сообщения вне порядка (`MAX_SKIPPED_KEYS = 64`)
- [x] Реализованы `derive_login_id`, `OpaqueAccountEnvelope`, `OpaqueClientSession`, `AppDisguiseConfig`, `ChatPinLock`, `RecoveryPhrase` (24 слова) и `SupporterPass`
- [x] Реализована `EncryptedVaultDb` с исчезающими сообщениями, заметками «Избранное», локальным поиском и экспортом/импортом бэкапов (`AEGISBAK`)
