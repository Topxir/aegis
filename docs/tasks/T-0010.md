# T-0010 — Песочница плагинов, темы оформления и защита от эксфильтрации
Модуль(и): `aegis-plugins`, `aegis-ffi` · Фаза: 7 · Приоритет: средний · Тип: feature

## Цель
Обеспечить безопасное выполнение тем и WASM-плагинов с жёстким запретом доступа к криптоключам и защитой от эксфильтрации истории чатов по сети.

## Контекст
- `docs/PLAN.md` §10, §13
- `docs/DECISIONS.md` D-0018

## Критерии приёмки
- [x] Декларативные темы не требуют исполняемого кода и сетевых прав
- [x] Любая комбинация чтения чатов + доступа к сети блокируется (`ExfiltrationRisk`)
- [x] Доступ к ключам (`requested_key_access`) безусловно отвергается (`KeyAccessForbidden`)
