# T-0013 — Чистая чат-крепость без звонков (Pure Chat Fortress), анти-правительственный Red-Team хакатон-аудит, уникальный интерфейс «Phantom Monolith», Clean-Room IP проверка и очистка релизных билдов
Модуль(и): все модули (`aegis-crypto`, `aegis-identity`, `aegis-storage`, `aegis-protocol`, `aegis-transport`, `aegis-server`, `aegis-directory`, `aegis-launcher`, `aegis-plugins`, `aegis-ffi`, `aegis-ui-desktop`, `aegis-ui-android`), `builds/`, CI · Фаза: 9 (Anti-State Fortress) · Приоритет: критический · Тип: security | contract-change | feature

## Цель
1. **Полное удаление звонков (`aegis-calls` и всех голосовых/видео функций):**
   - Удалить крейт `aegis-calls` из workspace и зависимостей, убрать все кнопки/оверлеи звонков из `aegis-ui-desktop` и `aegis-ui-android`, убрать разрешения `RECORD_AUDIO` и `CAMERA` из `AndroidManifest.xml` (чтобы приложение физически не запрашивало доступ к микрофону и камере у ОС!). Оставить исключительно сверхзащищённые чаты, локальный сейф «Избранное» и текстовые/View-Once капсулы.
2. **Очистка папки `builds/` и GitHub Workflows до самых важных глобальных билдов:**
   - Удалить лишние/отладочные файлы (`aegis-messenger-debug.apk`, дублирующиеся батники и черновики).
   - Оставить только ключевые глобальные релизные артефакты:
     - `builds/android-apk/aegis-messenger-release.apk`
     - `builds/desktop/aegis-desktop.exe`
     - `builds/server/aegis-serverd.exe` (+ `deploy-static-ip-vps.sh`, `docker-compose.yml`)
     - `builds/SHA256SUMS.txt` и `builds/README.md`
3. **Хакатон-аудит безопасности роем агентов против угроз уровня государства (Nation-State / DPI / Forensics):**
   - Провести параллельный аудит всеми субагентами на предмет новых нестандартных векторов атак (тайминг-атаки, криптографическое связывание очередей, DPI-анализ трафика, форензика памяти после `crypto_wipe`, атаки через браузер/ОС) и внедрить защиту.
4. **Уникальный авторский дизайн интерфейса «Aegis Phantom Monolith» (Desktop + Android) и Clean-Room IP аудит:**
   - Разработать самобытный интерфейс «Тактический Квантовый Монолит» (капсулы шифротекста `SEALED CAPSULE`, живая телеметрия паддинга и ратчета, матрица маршрутизации Static-IP / Tor, нулевое сходство с Telegram/Signal/WhatsApp/Discord).
   - Проверить юридическую и кодовую чистоту (100% Clean-Room реализация по открытым RFC/FIPS стандартам без единой строчки чужого проприетарного или GPL-несовместимого кода).
5. Пересобрать глобальные билды на ПК, проверить все автотесты и отправить (`git push`) в GitHub.
