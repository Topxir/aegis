# Журнал решений

Статусы: **ПРИНЯТО** · **ПРЕДЛОЖЕНО** (ждёт владельца) · **ОТКЛОНЕНО**
Формат: ID · контекст · варианты · выбор · последствия.

## D-0001 · Язык ядра: Rust — ПРЕДЛОЖЕНО
Контекст: безопасность памяти, единое ядро для всех платформ.
Варианты: Rust (+UniFFI) / Kotlin Multiplatform / C++.
Выбор: Rust. Последствия: нужны Rust-разработчики, биндинги в Kotlin/Swift.

## D-0002 · Сетевая модель — ПРЕДЛОЖЕНО (ждёт владельца)
Варианты: A) аккаунты на сервере; B) односторонние анонимные очереди без глобальных ID (как SimpleX).
Рекомендация: B (нет графа контактов, пользователей нельзя найти).
Последствия B: сложнее протокол, лучше метаданные.

## D-0003 · Лицензия: AGPL-3.0 — ПРЕДЛОЖЕНО
Контекст: форки сервера не должны закрывать код. Файл LICENSE уже в репозитории.

Отдельный аккаунт/организация, noreply-почта, без личных данных в git-метаданных.
