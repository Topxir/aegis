# Контракт: aegis-plugins
Версия контракта: 0.1

## Ответственность
Обеспечивает безопасное исполнение пользовательских модов, декларативных тем и WASM-плагинов в изолированной песочнице (PLAN.md §10, AGENTS.md §2 п.6, §3):
- Валидация манифестов прав плагинов (`PluginManifest`) по принципу минимальных привилегий;
- Строгое разделение на:
  - **Декларативные темы (`declarative_theme_only = true`)** — только токены цветов, шрифтов и отступов, 0 байт исполняемого кода и 0 рантайм-разрешений;
  - **WASM-плагины (`wasmtime`)** — изолированная среда без доступа к файловой системе, с выключенной по умолчанию сетью (`allow_proxied_network = false`) и гранулярным доступом только к явно разрешённым пользователем чатам (`allowed_read_chats`);
- Структурный запрет доступа плагинов к криптографическим ключам, паролям, PIN и сырой базе данных `aegis-storage` (`AGENTS.md §2 п.6`).

## Публичное API (функции, типы, ошибки)

### Типы
- `PluginManifest { plugin_id: String, declarative_theme_only: bool, allowed_read_chats: Vec<[u8; 16]>, allow_proxied_network: bool, requested_forbidden_key_access: bool }`
- `PluginError`:
  - `ForbiddenKeyAccessRequested` — плагин запросил доступ к ключам или сырому хранилищу;
  - `ThemeCannotRequestRuntimePermissions` — декларативная тема запросила доступ к чатам или сети;
  - `InvalidPluginIdentifier` — пустой или некорректный идентификатор плагина.

### Основные функции
- `validate_manifest(manifest: &PluginManifest) -> Result<(), PluginError>`

### Ошибки (`PluginError`)
- См. перечисление `PluginError` выше. Любое нарушение правил песочницы приводит к немедленному отказу в загрузке плагина (**Fail Closed**).

## Гарантии
1. **Плагины никогда не видят ключей (AGENTS.md §2 п.6):** в API хоста WASM-песочницы физически отсутствуют функции чтения ключей `aegis-crypto`, `aegis-identity` или `aegis-storage`. Любой манифест с `requested_forbidden_key_access = true` отвергается с `PluginError::ForbiddenKeyAccessRequested`.
2. **Безопасность декларативных тем (PLAN.md §10):** темы не могут запрашивать доступ к чтению чатов или сети (`ThemeCannotRequestRuntimePermissions`).
3. **Сеть только через защищённый транспорт:** даже если пользователь явно разрешил плагину `allow_proxied_network = true`, весь трафик плагина принудительно маршрутизируется через `aegis-transport` (под защитой `Network Anonymity Shield` и Kill Switch).

## Запрещено вызывающему
- Запрещено запускать WASM-модуль до успешного прохождения `validate_manifest` и явного подтверждения запрошенных прав пользователем в UI.
- Запрещено пробрасывать в WASM-песочницу системные сокеты ОС или файловые дескрипторы.

## Зависимости
- Внутренние модули: `aegis-protocol` (ограниченно: только безопасные DTO сообщений для разрешённых чатов).
