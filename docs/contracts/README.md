# Контракты модулей

> ⚠ **Контракты ниже описывают текущий прототип T-0016** (самописная
> криптография, старые invite/OPAQUE/static IP). После security reset
> (D-0024, D-0025) они будут заменены контрактами v2 в Phase 1. Не
> использовать старые контракты как источник для новой реализации.

Для каждого модуля из карты (AGENTS.md §3) создаётся файл `<модуль>.md` со структурой:

```md
# Контракт: aegis-<модуль>
Версия контракта: 0.1
## Ответственность
## Публичное API (функции, типы, ошибки)
## Гарантии
## Запрещено вызывающему
## Зависимости
## История изменений
```

Изменение контракта: только через задачу `contract-change` + запись в DECISIONS.md.
